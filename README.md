# Miljodataanalyse-1
Denne aplikasjonen henter inn data fra frost.met.no sitt API. Datasettet brukes til å regne sammenhenger og prediksjon som korrelasjon. I tillegg visualiseres dem i et kart og en rekke grafer. Heatmap, scatterplot og linjediagram. 

## Struktur
Kort forklaring av mapper og filer:

### 'data/': 
All data vi har hentet inn fra API-er og lagret som csv. 

### 'docs/': 
Filer og dokumenter som hører til oppgven. Evaluering og KI-deklarasjon ligger her. 

### 'src/': 
Kjernekode og funksjoner knyttet til databehandling og fremstilling. 

### 'tests/'
Enhetstesting for de ulike modulene under 'src/prosessing/'
